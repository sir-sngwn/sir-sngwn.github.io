C++ 마스터리: STL부터 알고리즘까지

모던 C++(C++17/20)을 기반으로 한 표준 템플릿 라이브러리(STL)의 핵심 컨테이너 구조, 반복자, 시간 복잡도 분석 및 실전 문제 해결을 위한 필수 알고리즘 종합 가이드입니다.

읽는 시간: 약 8분
Resolves: Issue #3

1. C++ STL 개요 및 4대 구성 요소

표준 템플릿 라이브러리(Standard Template Library, STL)는 C++ 언어의 가장 강력한 무기 중 하나로, 데이터 구조와 알고리즘이 템플릿 기반으로 추상화되어 있어 높은 성능과 재사용성을 동시에 보장합니다.

1. 컨테이너 (Containers)
데이터를 저장하는 구조체 (시퀀스, 연관, 비순서, 어댑터). 동적 배열, 연결 리스트, 해시 테이블, 트리 등 구현체 제공.
2. 반복자 (Iterators)
컨테이너 내부 원소를 순회할 수 있는 포인터의 일반화. 컨테이너와 알고리즘을 연결하는 접착제 역할.
3. 알고리즘 (Algorithms)
정렬, 이분 탐색, 순열, 변형 등 100개 이상의 검증된 고성능 알고리즘 함수군 (`<algorithm>`).
4. 함수 객체 (Functors & Lambdas)
사용자 정의 비교기, 필터링 조건 등을 람다 표현식 및 `std::function` 형태로 전달 가능.
성능 최적화 팁: 빠른 입출력 (Fast I/O)
알고리즘 문제 풀이나 대용량 데이터 처리 시 std::cin, std::cout의 병목을 없애기 위해 main() 진입 시 아래 두 줄을 필수 설정하세요: 
std::ios::sync_with_stdio(false);
std::cin.tie(nullptr);

2. 시퀀스 컨테이너 (Sequence Containers)

원소가 삽입된 순서(Linear Order)를 유지하는 컨테이너입니다. 데이터 접근 및 삽입 위치에 따라 적절한 컨테이너를 선택해야 합니다.

컨테이너 내부 구조 임의 접근 (Random Access) 앞쪽 삽입/삭제 뒤쪽 삽입/삭제 중간 삽입/삭제
std::vector 연속된 동적 배열 $O(1)$ $O(N)$ $O(1)$ amortized $O(N)$
std::deque 고정 크기 청크(Chunk) 배열 $O(1)$ $O(1)$ $O(1)$ $O(N)$
std::list 이중 연결 리스트 $O(N)$ $O(1)$ $O(1)$ $O(1)$ (위치 알고 있을 시)
vector_usage.cpp
C++20 
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    std::vector<int> v = {5, 2, 8, 1, 9};

    // 메모리 재할당 방지를 위한 reserve 권장
    v.reserve(10);

    v.push_back(4);
    v.emplace_back(7); // 객체 직접 생성(복사/이동 비용 절감)

    // 범위 기반 for 문 (Modern C++)
    for (const auto& elem : v) {
        std::cout << elem << ' ';
    }
    std::cout << '\n';
    return 0;
}
deque_usage.cpp
C++20 
#include <iostream>
#include <deque>

int main() {
    std::deque<int> dq;
    // 양방향 끝에서 O(1) 삽입/삭제 가능
    dq.push_front(10);
    dq.push_back(20);
    dq.push_front(5);

    while (!dq.empty()) {
        std::cout << dq.front() << ' ';
        dq.pop_front();
    }
    return 0;
}
list_usage.cpp
C++20 
#include <iostream>
#include <list>

int main() {
    std::list<int> lst = {1, 2, 3, 4};
    auto it = std::next(lst.begin(), 2);
    lst.insert(it, 99); // 중간 삽입 O(1)

    for (int n : lst) std::cout << n << ' ';
    return 0;
}
주의: 반복자 무효화 (Iterator Invalidation)
std::vector의 capacity를 초과하여 원소를 삽입하면 전체 버퍼가 새 메모리로 복사되며 기존의 모든 포인터, 참조자, 반복자가 무효화(dangling)됩니다. 대량 삽입 전 반드시 reserve()를 사용하세요.

3. 연관 & 비순서 컨테이너 (Map & Set)

키(Key)를 기반으로 빠른 검색을 지원하는 컨테이너입니다. 정렬 순서가 필요하면 레드-블랙 트리 기반을, 최상의 평균 속도가 필요하면 해시 테이블 기반을 선택합니다.

구분 컨테이너 내부 구현 시간 복잡도 (탐색/삽입/삭제) 키의 정렬 여부
연관 (Ordered) std::set, std::map Red-Black Tree (균형 이진 탐색 트리) $O(\log N)$ (항상 보장) 오름차순 자동 정렬
비순서 (Unordered) std::unordered_set, std::unordered_map Hash Table (해시 버킷) $O(1)$ avg / $O(N)$ worst 순서 없음 (무작위)
map_vs_unordered_map.cpp
C++20 
#include <iostream>
#include <map>
#include <unordered_map>
#include <string>

int main() {
    // 1. std::map: 키 기준 자동 정렬 유지 (O(log N))
    std::map<std::string, int> scoreMap;
    scoreMap["Charlie"] = 85;
    scoreMap["Alice"] = 95;
    scoreMap["Bob"] = 90;

    std::cout << "--- std::map (정렬 순 출력) ---\n";
    for (const auto& [name, score] : scoreMap) {
        std::cout << name << ": " << score << '\n';
    }

    // 2. std::unordered_map: 해시 기반 최고 속도 (평균 O(1))
    std::unordered_map<std::string, int> fastCache;
    fastCache["token_alpha"] = 1001;

    // 안전한 탐색: find() 활용
    if (auto it = fastCache.find("token_alpha"); it != fastCache.end()) {
        std::cout << "Found: " << it->second << '\n';
    }
    return 0;
}

4. STL 알고리즘 핵심 활용 (<algorithm>)

C++ 표준 알고리즘은 반복자를 통해 컨테이너와 독립적으로 동작하며, 최적화된 어셈블리로 컴파일됩니다.

1
정렬 및 사용자 정의 비교기 (std::sort)
평균 $O(N \log N)$ 인트로소트(Introsort)를 사용합니다. 모던 C++에서는 람다 표현식으로 커스텀 정렬 기준을 깔끔하게 정의할 수 있습니다.
2
이분 탐색 (std::lower_bound / std::upper_bound)
반드시 정렬된 상태에서 동작하며, $O(\log N)$ 만에 특정 값 이상/초과의 첫 원소 위치를 찾습니다.
3
모던 C++20 Ranges (std::ranges)
반복자 쌍(`v.begin(), v.end()`) 대신 컨테이너 자체를 전달할 수 있고, 파이프라인 연산자(`|`)를 통한 함수형 스타일 체이닝을 지원합니다.
algorithms_demo.cpp
C++20 
#include <iostream>
#include <vector>
#include <algorithm>
#include <numeric>

struct Student {
    std::string name;
    int score;
};

int main() {
    std::vector<Student> students = {
        {"Kim", 88}, {"Lee", 95}, {"Park", 95}, {"Choi", 70}
    };

    // 1. 람다 기반 다중 조건 정렬 (점수 내림차순 -> 이름 오름차순)
    std::sort(students.begin(), students.end(), [](const Student& a, const Student& b) {
        if (a.score != b.score) return a.score > b.score;
        return a.name < b.name;
    });

    // 2. 이분 탐색으로 특정 구간 카운팅 (std::vector<int>)
    std::vector<int> nums = {1, 2, 4, 4, 4, 6, 7};
    auto low = std::lower_bound(nums.begin(), nums.end(), 4); // 첫 번째 4의 반복자
    auto up  = std::upper_bound(nums.begin(), nums.end(), 4); // 4를 초과하는 첫 반복자
    std::cout << "4의 개수: " << std::distance(low, up) << '\n'; // 3

    // 3. std::accumulate를 활용한 총합 계산
    int total = std::accumulate(nums.begin(), nums.end(), 0);
    std::cout << "총합: " << total << '\n';
    return 0;
}

5. 실전 알고리즘 패턴 모음

코딩 인터뷰 및 알고리즘 대회에서 빈출되는 3대 핵심 패턴과 C++ 관용구입니다:

패턴 1: 투 포인터 & 슬라이딩 윈도우 (Two Pointers)
연속된 구간의 합이나 조건을 만족하는 부분 배열을 구할 때 $O(N^2)$을 $O(N)$으로 단축합니다. 
int left = 0, sum = 0, minLen = INT_MAX;
for (int right = 0; right < n; ++right) {
    sum += arr[right];
    while (sum >= target) {
        minLen = std::min(minLen, right - left + 1);
        sum -= arr[left++];
    }
}
패턴 2: BFS/DFS 그래프 탐색 (std::queue & recursion)
최단 거리는 std::queue 기반 BFS, 백트래킹 및 모든 경로 탐색은 DFS 재귀를 활용합니다. std::vector<std::vector<int>> 인접 리스트 구조를 기본으로 사용합니다.
패턴 3: 다이나믹 프로그래밍 (DP: Tabulation & Memoization)
중복 부분 문제와 최적 부분 구조를 갖는 문제를 점화식으로 환원하여 해결합니다. std::vector<int> dp(N + 1, -1); 메모이제이션을 적용합니다.
