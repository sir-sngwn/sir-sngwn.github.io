도구 호출 (Tool Calling) & Model Context Protocol

AI 모델이 외부 환경과 상호작용하기 위한 함수 호출 메커니즘과 개방형 표준 프로토콜인 MCP(Model Context Protocol) 연동 가이드입니다.

읽는 시간: 약 6분
Protocol: MCP 1.0

1. 함수 호출 (Tool Calling) 원리

현대 LLM은 사용자의 목표를 해석하고, 사전 등록된 도구(Tool)의 JSON Schema를 참조하여 적절한 함수 이름과 인자(Arguments)를 구조화된 데이터 형태로 생성합니다.

tool_schema.json
JSON 
{
  "name": "read_file",
  "description": "지정된 경로의 파일 내용을 확인합니다.",
  "parameters": {
    "type": "object",
    "properties": {
      "file_path": {
        "type": "string",
        "description": "읽을 파일의 절대 또는 상대 경로"
      },
      "max_lines": {
        "type": "integer",
        "description": "최대 읽을 라인 수 (기본값: 100)"
      }
    },
    "required": ["file_path"]
  }
}

2. Model Context Protocol (MCP) 개요

Model Context Protocol (MCP)은 AI 모델이 다양한 로컬 및 원격 데이터 소스(데이터베이스, 웹 브라우저, 로컬 Git 레포지토리, 클라우드 API)와 안전하고 표준화된 방식으로 연결되도록 지원하는 개방형 프로토콜입니다.

MCP Host (클라이언트)
Antigravity, Claude Desktop 등 사용자와 상호작용하고 다수의 MCP 서버를 조율하는 중앙 애플리케이션입니다.
MCP Server (도구 제공자)
특정 리소스(예: Postgres, GitHub, Filesystem)를 제어하고 표준화된 RPC 인터페이스로 기능을 노출합니다.

3. JSON-RPC 2.0 기반 메시지 교환

MCP는 표준 JSON-RPC 2.0 규격을 채택하여 신뢰할 수 있는 요청-응답 통신을 제공합니다:

request.json
JSON-RPC 
{
  "jsonrpc": "2.0",
  "id": 101,
  "method": "tools/call",
  "params": {
    "name": "search_code",
    "arguments": {
      "pattern": "initMobileSidebar",
      "path": "src/js/"
    }
  }
}
response.json
JSON-RPC 
{
  "jsonrpc": "2.0",
  "id": 101,
  "result": {
    "content": [
      {
        "type": "text",
        "text": "Found 1 match in src/js/app.js: Line 88: function initMobileSidebar()"
      }
    ],
    "isError": false
  }
}

4. 샌드박스 및 권한 격리 모델

에이전트가 도구를 실행할 때는 항상 권한 격리 원칙(Principle of Least Privilege)을 준수해야 합니다:

보안 수칙: 자동 승인 방지
사용자의 개인정보(토큰, SSH 키)에 접근하거나, 외부 임의 URL로 비인가 네트워크 요청을 전송하는 도구는 반드시 사용자 명시적 승인 모달을 띄워야 합니다.
