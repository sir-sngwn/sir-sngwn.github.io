재활용 가능한 UI 컴포넌트

기술 문서와 블로그, 에이전트 포털을 풍부하게 꾸밀 수 있는 모던 UI 컴포넌트 카탈로그입니다. 실제 동작하는 프리뷰와 함께 복사 가능한 HTML 스니펫을 제공합니다.

8 Types Components

1. 콜아웃 알림창 (Callout Alerts)

중요한 정보, 팁, 주의사항을 독자의 시선에 띄우기 위한 5가지 스타일입니다:

Note (참고)
배경 지식이나 추가 참고 정보를 전달할 때 사용합니다.
Tip (유용한 팁)
생산성을 높이는 권장 사용 팁이나 단축키를 안내합니다.
Important (중요)
반드시 알고 있어야 하는 핵심 요구사항입니다.
Warning (주의)
호환성 문제나 예기치 않은 오류가 발생할 수 있는 사항을 경고합니다.
Caution (위험)
데이터 손실 또는 보안 취약점을 유발할 수 있는 고위험 작업입니다.

2. 인터랙티브 코드 블록 (Code Blocks)

상단 파일명 바, 언어 뱃지, 원클릭 복사 버튼이 통합된 코드 블록입니다:

server.ts
TypeScript 
import { Server } from "@modelcontextprotocol/sdk/server/index.js";

const server = new Server({
  name: "custom-agent-tools",
  version: "1.0.0"
});

3. 다중 탭 컴포넌트 (Tabs)

서로 다른 언어, 포맷, 명령어를 깔끔하게 정리하는 탭 UI입니다:

npm install @modelcontextprotocol/sdk
pnpm add @modelcontextprotocol/sdk
yarn add @modelcontextprotocol/sdk

4. 에이전트 상태 뱃지 (Agent Badges)

에이전트의 현재 실행 상태 및 프로세스 생명주기를 시각화합니다:

Ready (준비) Running (실행 중 - 펄스) Completed (완료) Blocked (차단됨)

5. 스텝별 가이드 (Steps Timeline)

순차적 작업 절차를 시각적인 타임라인으로 표현합니다:

1
레포지토리 클론
Git을 통해 프로젝트 원격 저장소를 로컬로 내려받습니다.
2
환경 변수 설정
API Key 및 모델 엔드포인트를 환경 설정 파일에 등록합니다.

6. 접이식 아코디언 (Accordion / FAQ)

자주 묻는 질문이나 상세 기술 명세를 깔끔하게 수납합니다:

외부 프레임워크(React, Vue 등) 없이도 동작하나요?
네, 100% 브라우저 표준(HTML5, Modern CSS, Vanilla JS)만으로 구현되어 있어 빌드 과정 없이 즉시 GitHub Pages에서 작동합니다.
다크 모드는 어떻게 유지되나요?
사용자의 OS 설정(prefers-color-scheme)을 기본 감지하며, 헤더 우측의 테마 버튼으로 변경한 값은 localStorage에 영구 저장됩니다.
